# Valentine Request 💌

An interactive Valentine’s Day project that playfully asks for your Valentine’s response with fun animations and buttons.

## Demo
[Try it here](https://samuel-code1.github.io/1-Valentine-Request)

## Features
- Floating heart animations
- Playful Yes/No buttons
- Surprise Valentine message

## Setup
1. Clone the repo: `git clone https://github.com/Samuel-code1/1-Valentine-Request`
2. Open `index.html` in your browser
